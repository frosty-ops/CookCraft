# 🍳 CookCraft - AI Recipe Finder

![Python](https://img.shields.io/badge/Python-3.13-blue?logo=python)
![Flask](https://img.shields.io/badge/Flask-Web_App-black?logo=flask)
![HTML](https://img.shields.io/badge/HTML5-orange?logo=html5)
![CSS](https://img.shields.io/badge/CSS3-blue?logo=css3)
![JavaScript](https://img.shields.io/badge/JavaScript-yellow?logo=javascript)

CookCraft is a modern recipe finder web application built using **Python Flask**, **HTML**, **CSS**, and **JavaScript**.

Users can search recipes, explore trending meals, view detailed cooking instructions, and watch recipe videos from YouTube through a simple and attractive interface.

# 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/CookCraft.git
```

### 2. Open the project

```bash
cd CookCraft
```

### 3. Install required packages

```bash
pip install -r requirements.txt
```

### 4. Run the Flask application

```bash
python app.py
```

### 5. Open your browser

```
http://127.0.0.1:5000
```
